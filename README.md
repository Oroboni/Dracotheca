Nosso Trabalho de Conclusão de Curso (TCC) foi desenvolvido em parceria com meus colegas Luis Felipe Gluser Lucas, Bruna Elisa e Camila Inocencio. 
O projeto tem como objetivo a implementação de um Sistema de Gerenciamento de Biblioteca para a FATEC, otimizando o controle do acervo, empréstimos e devoluções.
Com essa solução, buscamos modernizar e facilitar a administração da biblioteca, proporcionando maior eficiência no acesso e na organização dos materiais disponíveis.
